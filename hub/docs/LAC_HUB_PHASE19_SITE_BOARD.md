# LAC HUB Phase 19 — 통합 공지·문의·건의 게시판

## 적용 순서 (중요)

1. 현재 사용 중인 **LAC HUB Supabase 프로젝트**의 SQL Editor에서 `database/migrations/LAC_HUB_PHASE19_SITE_BOARD.sql`을 **먼저 실행**한다. 새로운 테이블 4개, 비공개 사진 버킷 1개, RPC 및 RLS를 추가한다. 기존 회사·질문·건의·사진 데이터는 변경하거나 삭제하지 않는다. SQL 실행 전에는 신규 게시판의 조회/작성 기능이 동작하지 않는다.
2. SQL 실행 성공 후 Phase 19 **전체본 ZIP**을 기존 LAC-HUB GitHub Desktop 작업 폴더에 전체 복사·덮어쓰기한 다음 Commit → Push 한다. `.env` 운영값은 ZIP에 포함되지 않으며 기존 설정을 보존한다.
3. 배포 후 Discord 로그인한 **회사 없는 이용자**, **회사 멤버**, **플랫폼 운영자** 계정으로 각각 게시판을 확인한다. 문의 게시물/사진이 본인과 운영자 이외의 계정에서는 표시·조회되지 않는지 확인한다.

## 화면과 기능

- HUB 메인 배너와 콘텐츠 4열 카드 **사이에 독립 소식 패널** 배치: 최근 운영 공지 한 건(없으면 빈 공지 안내), `게시판 가기`, `문의 · 건의 작성`.
- `게시판 가기`는 메인과 분리된 HUB 전용 화면으로 이동한다. 문의·건의, 공지 탭을 별도로 제공한다.
- 문의 작성: **콘텐츠 유형**(회사 관리 / 게임 정보 / LAC BUILD / LAC COOK / LAC HUB)과 **문의 유형**(질문 / 건의 / 오류 신고)을 별개로 선택. 선택 항목을 문의 목록에 표시한다.
- JPG/PNG/WEBP 사진 최대 5장(장당 10MB), 파일 선택, 드래그·드롭, 클립보드 붙여넣기, 등록 전 미리보기/삭제, 작성자·운영자 전용 이미지 열기.
- 회사 없이 로그인한 이용자도 작성할 수 있다. 글과 사진은 작성자·플랫폼 운영자만 조회 가능하도록 DB RLS 및 비공개 Storage 버킷으로 제한한다.
- 운영자는 전체 문의 목록/답변/상태 변경, 공지 작성 가능. 공지는 로그인 이용자에게 공개된다.

## 기존 게시판 처리

기존 회사 관리의 질문/건의 글·답변·첨부는 **절대 삭제하지 않았다.** 회사 관리 사이드바의 일반 `문의 · 건의` 진입은 새로운 HUB 게시판으로 일원화했으며, 소속 회사가 있는 이용자는 HUB 게시판 하단의 **`이전 회사 문의 기록`**에서 과거 질문/건의 페이지를 열 수 있다. 기존 플랫폼 운영센터의 과거 문의 응답/알림 기능 역시 보존한다. 새 문의는 신규 게시판에 기록되고 과거 게시글은 자동 이전되지 않는다. 운영 DB에서 이전 글과 공개 범위 확인 후 별도 마이그레이션/기존 작성 버튼 정리 여부를 결정한다.

Vite 의존성이 현재 작업 환경에 없어 프로덕션 빌드는 실행하지 못했다. **SQL 실행 전 ZIP부터 배포하지 말 것.** 신규 게시판 답변에 대한 Discord DM 전송은 이번 단계에 포함하지 않았다.
