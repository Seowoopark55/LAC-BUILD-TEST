# LAC ONE R4 · 데이터 표 글씨 크기 전용 (WEB STAGING)

기준: R3 회사 개설 코드 + LAC ONE 로그인/배경 + 스튜디오 전체본.

- 메뉴/로그인/페이지 제목/필터/사이트 너비는 글씨 조절 대상에서 제외.
- 공금내역·공금 기록 및 결재·멤버·자산·계좌·요리 표의 머리글/데이터/상태/표 안 버튼만 기존 폰트 비율대로 조절.
- 스튜디오 슬라이더 하나: 90–150%; 100%에서는 기존 UI 변경 없음. 현재 선택 값은 이 브라우저에 저장.
- R3에서 저장된 전체 글씨 크기 값은 첫 실행 시 표 전용 배율로 가져옴. ‘기본값’ 누르면 새/이전 배율 설정 모두 지움.
- 표 행 높이만 조정하고, 폭이 부족한 표는 카드 내부 가로 스크롤을 허용. 사이트 전체 프레임/로그인/모달은 확대하지 않음.
- 회사 개설 코드 관련 DB 보안 SQL은 이 ZIP에 자동 적용되지 않음. 별도의 선행 검토 없이 실행하지 말 것.
- 기존 AXE NET, 기존 운영 AXE BOT은 수정하지 않음. WEB STAGING 전체본으로만 적용할 것.
- 로컬 정적 검사는 통과했으나 이번 작업 환경에서 최종 Vite 빌드와 실제 Chromium 화면 검증은 완료하지 못함. STAGING에서 100%, 120%, 140%로 공금/멤버/자산 표 검증 필요.
