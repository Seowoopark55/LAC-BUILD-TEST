# AXE ONE WEB — 정보 기능 1차 STAGING 검토본

기준: 사용자가 업로드한 `axe one(2).zip` 전체본.

이번 단계: 6개 공통 정보 테이블 읽기 전용 조회·검색 화면, 공용 '게임 정보' 사이드바 항목, 기존 질문/건의게시판을 하나의 '문의 · 건의' 메뉴와 화면 내부 2개 탭으로 통합. 각 게시판의 기존 URL(앱 내부 route), 데이터 처리, 알림 구분, 질문/건의 작성·답변 흐름은 유지.

- 일반 멤버도 게임 정보 페이지에 접근할 수 있도록 기존 회사관리자 전용 화면 가드 이전에 정보 화면을 처리합니다.
- 기존 DB 및 AXE NET은 수정하지 않았습니다. `platform_info_set_active`는 호출하지 않습니다.
- 이 버전은 의도적으로 읽기 전용입니다. PLATFORM OWNER의 실제 정보 추가·수정, 비활성화 및 감사 로그 연결, BOT 조회/필터 변경은 다음 단계에서 별도 구현·검증합니다.
- 비활성 데이터는 일반 조회에서 제외합니다. PLATFORM OWNER에게만 비활성 포함 필터를 표시합니다.
- 실제 SQL 수정 없이 기존 `axe_product` 6개 정보 테이블의 authenticated SELECT 권한을 사용합니다.

검증: 기존 `npm run check` 통과; 신규 `node scripts/info-catalog-stage1-check.mjs` 통과; JS 문법 검사 통과. 이 컨테이너에서는 npm 패키지 설치 네트워크 오류로 `npm run build` 및 실제 인증·렌더링 테스트를 수행하지 못했습니다. STAGING Vercel Ready 및 브라우저에서 각 권한별 조회와 사이드바 스크롤 여부를 먼저 확인하십시오. 운영 사이트 배포본 아님.

수정된 기존 테스트 4개는 사용자가 승인한 지원 메뉴 통합 및 정보 route 추가를 반영했으며, 기존 42장 스크린샷 baseline은 갱신하거나 삭제하지 않았습니다.
