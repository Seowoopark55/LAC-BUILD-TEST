# LAC HUB 20차: 메인 소식 및 고객지원 UI 고급화

기준: 19차 LAC HUB 통합 게시판 전체본. **새 데이터베이스 마이그레이션 없음**. 이미 19차 SQL을 적용했다면 다시 실행할 필요 없음. 아직 적용 전이라면 배포 전에 19차 SQL을 먼저 적용해야 함.

- HUB 배너, 계정 정보, 콘텐츠 카드 4개 및 회사 생성 제한은 그대로 유지. MY SPACE 재도입 없음.
- 메인 배너 아래에 LAC 소식(실제 최신 공지 최대 2건)과 문의·건의(게시판 보기/작성) 독립 패널 배치. 공지가 없을 때 실제 빈 상태 메시지 표시.
- 고객지원 화면에 별도 배경 이미지 헤더, 분명히 분리된 문의·건의 / 공지사항 탭, 좌측 안내/오른쪽 DB 목록, 콘텐츠/문의유형/답변상태 및 표시된 글 검색 추가. 관리자도 현재 불러온 글에 대해서만 `N건 표시 중`으로 표기; 전체 게시글 수로 오해하지 않도록 함.
- 각 문의는 기존과 같이 작성자 및 플랫폼 관리자에게만 보임. 게시판에 다른 사람들의 가상 글이나 외부 사용자에게 공개되는 답변 현황을 추가하지 않음.
- 기존 문의·답변 작성, 사진 선택/붙여넣기/미리보기, 공지 관리, 회사 관리의 이전 글 링크, Supabase RLS/SQL/데이터는 변경 없음.
- `public/hub/board/`에는 생성된 이미지 중 실제 화면에서 사용한 4개를 WebP로 최적화하여 저장. 이미지에 텍스트/버튼을 합성하지 않고 실제 HTML 오버레이로 표현.

검증: `node scripts/hub-phase19-site-board-check.mjs` 및 `node scripts/hub-phase20-support-premium-check.mjs`, `npm run check`, 로컬 Chromium의 홈/문의 목록(빈 경우·테스트 글)/공지/작성/모바일 미리보기. 실제 Discord 세션/Supabase 운영 DB에서의 CRUD·사진 업로드 검증은 배포 후 필요.
