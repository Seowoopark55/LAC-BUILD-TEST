# LAC HUB Phase 18 — 메인 회사 진입 동선 정리

기준: `LAC_HUB_PHASE17_HOME_COPY_CLEANUP_FULL.zip`. 이번 변경은 HUB 메인의 사용자 동선과 회사가 이미 설정된 계정의 UI 중복 생성 진입점 정리에 한정합니다.

## HUB 메인

- `MY SPACE` 표시줄 및 중복된 상단 `내 회사` 메뉴를 제거했습니다.
- 로그인한 계정에 **현재 선택된 회사가 있으면** 상단 계정 영역에 회사명이 표시됩니다. 기존 데이터에 복수 회사가 연결된 경우 해당 위치에서 회사 전환을 계속할 수 있습니다.
- 배너의 유일한 회사 진입 버튼은 현재 회사가 있으면 `내 회사로 이동`(기존 회사 콘솔), 없고 DB 기반 회사 생성 권한이 확인되면 `+ 회사 생성`(기존 회사 등록·가입 안내 화면)을 표시합니다.
- 회사가 없지만 생성 권한이 없으면 `회사 가입 안내`, 권한을 확인하지 못했다면 `회사 등록 안내`를 표시합니다. 두 경우 모두 기존 첫 실행 안내 화면으로 이동하며, 생성이 허용되지 않는 경우 기존 권한 안내가 유지됩니다.
- 콘텐츠 4개, 기존 가입 안내, 관리 센터 권한 및 게임 정보 접근은 유지됩니다.

## 이미 설정된 회사에서 추가 생성 방지

- 회사 콘솔 사이드바의 `+ 새 회사` 진입점을 제거했습니다. 회사의 멤버이지만 아직 회사 생성 이력이 없어 DB RPC에서 `canCreateCompany=true`를 받는 사용자에게도 나타나지 않습니다.
- 클라이언트 액션 및 생성 폼 제출에서 `state.companies.length`를 추가로 확인하며, 기존의 DB 생성 권한 조회·개설 코드 확인·DB 검증 로직은 변경하지 않습니다.
- 서버 DB 스키마나 RLS 정책을 변경하지 않았습니다. 서버의 추가 회원사 생성 금지 여부는 기존 DB 정책과 별개의 문제이므로 이 패치만으로 새로운 DB 강제 제약이 생기지는 않습니다.
